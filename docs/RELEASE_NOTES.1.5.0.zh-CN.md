# ResearchFlow 1.5.0 更新说明

发布日期：2026-10-26 · Windows 10 / 11 x64

ResearchFlow 1.5.0 将高频工作入口收拢，并补充周进度整理、排序与主项目 / 子项目关系。科研数据继续保存在本机，数据结构仍兼容 schemaVersion 2。

## 科研进度周报

“状态回顾”增加“导出科研进度”。按自然周选择项目后，可预览并导出 Markdown，或复制供外部 AI 使用的总结提示词。周报汇总真实完成行动、当前阶段、未完成行动、计划时段、专注记录、成果卡和待解决问题。默认项目选择包含本周记录及覆盖本周的计划时段；不会推算完成比例或生成研究结论。复制或导出前显示隐私提醒；软件不连接外部 AI 服务。

## 阶段与行动排序

路线图阶段和阶段内行动可拖动排序，并保留上移 / 下移操作。排序立即写入本机；行动不会因排序改变阶段归属、状态、日期或专注记录。旧行动未保存顺序时，仍按已有数组顺序显示。

## 悬浮窗多项目切换

悬浮窗可以在符合当天安排的进行中项目间切换；当天没有安排时显示其他进行中项目。切换会更新当前科研重点与建议行动。已有专注计时会继续运行，并清楚标示正在专注的项目；管理窗口行动视角使用相同筛选规则。

## 更简洁的导航与主项目 / 子项目

主导航聚焦概览、科研规划、行动视角和科研项目。问题探索与成果产出合并为项目方向筛选，重启卡由暂停项目筛选和概览入口访问；成果卡、灵感池与状态回顾归入“研究记录”。原有路由仍可使用。

项目可选择一个所属主项目，支持一级关系。主项目和子项目分别管理自己的阶段、行动、计划、成果与专注记录，不自动继承状态。删除主项目只解除子项目关系并保留其记录。名称相同的真实项目不会被错误识别为示例或被批量删除。

## 数据兼容与隐私

新增 `mainProjectId` 和行动 `order` 均为可选字段，保持 `schemaVersion: 2`；现有数据与 JSON 备份无需迁移。验证在保存前拒绝自引用、悬空或多级项目关系，失败时不写入无效备份。未增加运行时依赖、云服务或 AI 接口。

实际测试与本机 Windows 桌面验证范围见随包《验收报告》和开发记录中的测试截图。系统 DPI、多显示器和不同电脑的安装情况未验证时会在报告中明确标注。

升级前请保存未提交的表单，并通过托盘“完全退出”正在运行的旧版，再安装新版。建议重要科研整理后导出 JSON 备份。

# ResearchFlow 1.2.1

AI 科研计划导入现在自动带入当前项目名称，并通过完整的协作提示词引导外部 AI 讨论计划后生成可导入的 JSON。

- 当前项目名称同时填入项目资料区与 JSON 示例；含引号、反斜杠等字符时，示例仍保持合法 JSON。
- 明确介绍 ResearchFlow 的使用场景，按理解项目、拟定阶段与行动、逐轮调整、明确确认后交付的顺序开展讨论。
- 区分研究项目本身的成果与 AI 的最终交付：后者是一份 UTF-8 的 researchflow-plan version 1 JSON 文件；平台不能生成附件时可直接交付 JSON 文本。
- 明确大阶段目标、阶段成果、小目标与具体行动的两层对应关系，补充完成标准、前置条件、等待时间和不确定事项的填写指导。
- 补全受支持字段、日期与分钟含义、数量和文本限制、输出自检要求，避免生成不能导入的多层子任务或虚构排期。
- 导入页“复制提示词”现在保留准备页中的用户编辑。

本次未修改导入协议、持久化 schema 或原生窗口与存储逻辑，没有新增依赖。

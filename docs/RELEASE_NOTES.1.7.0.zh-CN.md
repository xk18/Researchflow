# ResearchFlow 1.7.0 更新说明

- 全局精简：删除重复说明、口号和填充文案；保留必要验证、空状态、隐私与删除确认。项目背景默认收起，稳定柔和边框区分项目，操作改为有名称提示的图标。
- 行动视角：项目选择、阶段、行动与图形时钟集中显示。图标控制专注，更多菜单提供备注、编辑与稍后推荐。当前专注仍绑定真实项目，不会因切换项目而结束。
- 可编辑流程图：图内创建阶段、子阶段和行动；双击编辑，侧栏修改状态、层级和同层顺序。支持阶段/行动拖放，项目根节点用于提升或移至未分组。侧栏下拉框和按钮提供键盘替代。
- 安全关系：拒绝自引用、循环、跨项目和失效关联。删除阶段需确认，行动移至未分组，子阶段提升一级。ID、日期、状态、专注和成果不会因层级移动被重建。
- 全局字号：设置→外观，12–18，默认14，保存并同步至管理页、弹窗、月历、流程图与悬浮窗。
- schemaVersion仍为2，新增可选Milestone.parentMilestoneId与Settings.fontSize。旧数据无需重建，AI交换格式保持researchflow-plan version1平面阶段。
- 应用标识与用户数据路径保持不变，新版首次读取前保存原版本副本；不会自动注入示例或覆盖偏好。

完整验证范围与限制见本版本验收报告。截图来自真实浏览器运行，不能替代原生桌面、多窗口、安装覆盖及系统DPI验证。

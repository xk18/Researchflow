# ResearchFlow 1.3.1：科研月历

跨日安排现在在每个日期内显示独立彩色标签，不再遮盖日期格线。月份按实际4、5或6周分配可用高度；900×650窗口中完整显示月末，过小窗口保留月历区域内滚动。

- 项目ID决定六种柔和识别色，改名、换月、筛选不会重新分色；色池有限，不保证所有项目颜色唯一。浅色与深色主题分别设置标签背景、文字与网格层级。
- 长名称单行省略，悬停可见完整名称和日期。截止目标用旗标、阶段用菱形、总体项目日期用圆点与虚线边框区分。
- 每格根据高度显示1至5个标签，余项通过“+N 项”打开当天详情。同项目同日多个时段只合并视觉标签，独立记录、备注与编辑入口全部保留。
- 单个计划标签可直接编辑，含多个时段或节点的标签打开详情；日期数字和空白区域查看当天安排。键盘焦点与月历/时间轴切换保留。
- 仅新增只读日期投影，无数据迁移、额外依赖、在线服务或重复的持久化计划。日期经过不代表工作完成。

主要实现位于src/calendar.ts、src/components/MonthCalendar.tsx、src/pages/Planning.tsx、src/styles.css；App.tsx调整规划页留白。tests/calendar.test.ts和tests/ui/calendar.spec.ts覆盖跨月、空档、重叠、长标题、溢出详情及4/5/6周布局。

验证：69项单元测试、23项界面测试、6项Rust测试通过；TypeScript与Vite生产构建、Windows x64 NSIS构建通过。独立应用标识的原生WebView在900×650、100%缩放下完成五周/六周截图、密集详情、保存重读及正常退出检查。系统125%–200% DPI、多显示器切换和其他电脑首次安装尚未实测。

本轮未改动核心专注与存储机制。截图使用隔离验收数据，不会把演示记录加入正式科研数据库。

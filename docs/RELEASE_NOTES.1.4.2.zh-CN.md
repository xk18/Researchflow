# ResearchFlow 1.4.2 更新说明

发布日期：2026-10-14 · Windows 10 / 11 x64

## 概览页精简

概览现在按“近期计划 → 当前行动 → 辅助记录”组织。近期科研时间轴保留真实日期、独立时段、阶段节点和项目目标，但默认只预览少量重点项目；窄矮窗口会进一步减少预览数量，完整规划入口仍可查看全部安排。

时间轴不再让重叠安排无限撑高项目行。重叠时段可以从“另 N 段”打开，聚合节点和跨月时段仍保留各自日期与来源。阶段名只有在有足够像素空间时显示，完整名称通过键盘焦点、悬停提示和详情入口访问。

当前项目、当前阶段和下一步行动已合并为连续上下文。行动所属阶段读取行动真实的 `milestoneId`；无分组行动不会被误标到项目当前阶段。行动标题和“开始专注”是主要焦点，说明支持按需展开，计时、动力、暂停、继续、结束和完成仍沿用原业务语义。

成果卡与重启入口改为底部轻量行；没有待恢复内容时不再占用大块空状态区域。长中文、深浅主题和窄窗口均使用原始数据，不修改用户输入。

## 兼容与验证

保持 schemaVersion 2、科研数据路径、JSON 备份恢复和推荐规则不变，不增加运行时依赖或联网服务。只读时间轴预览不会写入项目、阶段、行动或计划时段。

本版已通过：89 项单元测试、40 项浏览器界面测试、TypeScript/Vite 生产构建及 6 项 Rust 测试；完整同步时重新执行检查和 NSIS 安装包构建。已针对 900×650、720×560、900×900、深色主题、长中文、重叠时段、无分组行动和空工作区保存真实运行截图。

Windows 原生验收使用独立 identifier 的调试宿主加载本版生产前端，已验证示例数据保存重读、900×650 主操作首屏可见、手动主线预览、说明与选项、计时开始/暂停/继续/结束、卡片同步、深色主题、胶囊显示和正常退出重启后的数据保留；未访问正式用户科研数据。125%/150% Windows DPI、多显示器、系统睡眠及其他电脑上的安装仍未验证，原生调试宿主验收不能替代这些平台专项检查。

升级前请保存编辑内容、导出 JSON，并通过托盘“完全退出”旧版。详细操作见 [新手使用说明书](USER_GUIDE.zh-CN.md)，分发文件见 [分享与分发说明](DISTRIBUTION.zh-CN.md)。

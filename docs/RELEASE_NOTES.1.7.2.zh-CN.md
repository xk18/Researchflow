# ResearchFlow 1.7.2

这一版主要调整两件日常工作：随手记待办，以及自己决定月历里每天推进什么。

## 新增待办

在“研究记录 → 待办”快速录入事项，支持完成与重新打开、编辑内容和日期、查看其他日期、汇总全部未完成以及确认删除。待办独立于项目行动，包含在 JSON 备份、恢复和合并中。

## 月历按需安排

项目启动日和目标日仍显示节点，但两者之间的日期不再自动填满。点击日期安排研究时，优先显示日期范围内的进行中项目，也可选择其他进行中项目；支持关联研究阶段。新计划默认不勾选重点，编辑已有计划保留原设置。

已经保存的多日计划不会被清空。时间轴继续显示项目整体日期范围；总体范围不表示每天持续投入。

## 数据与升级

沿用 schemaVersion 2，新增可选 todos 与计划 milestoneId。旧项目、阶段、行动、计划和外观偏好不自动重写。升级沿用原应用标识和数据目录，正常首次读取新版前保存旧数据副本。仍建议先导出 JSON、保存表单并从托盘完全退出旧程序。

## 下载

普通用户下载 ResearchFlow_1.7.2_x64-setup.exe 或 Windows-x64-share.zip。需要 Windows 10 / 11 x64 和 WebView2；缺少运行库时首次安装可能联网。当前安装包未签名。安装、分享及源码分发须遵守 PolyForm Noncommercial 1.0.0 和第三方许可。

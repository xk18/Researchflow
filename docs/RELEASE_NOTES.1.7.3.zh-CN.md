# ResearchFlow 1.7.3

本次修复概览、悬浮组件和行动视角中的项目切换问题。

## 项目切换

- 可以选择所有已有项目，不再因没有今日计划、没有日期或未设重点而被隐藏。当日有安排的进行中项目优先排列。
- 新建项目或行动后，可以直接在列表中切换。添加行动时默认使用当前选中的进行中项目及其当前阶段。
- 暂停、已完成、已归档和已终止项目带有状态说明。选中不会自动恢复；需要继续工作时，可打开项目并恢复为进行中。
- 切换项目保留已有专注，并显示本次计时所属项目。结束后显示新选项目的行动；结束专注不会自动完成行动。
- 前后切换与下拉选择使用同一份列表，选择保存后同步到另一个窗口，重启后保留。

## 下载与升级

Windows 10 / 11 x64，需要 Microsoft Edge WebView2。普通用户下载 `ResearchFlow_1.7.3_x64-setup.exe`；也可下载 `ResearchFlow-1.7.3-Windows-x64-share.zip`，内含安装包、说明书与许可文件。

说明书单独提供为 `ResearchFlow-1.7.3-user-guide.pdf`；源码包为 `ResearchFlow-1.7.3-source.zip`。附件校验值见 `SHA256-release-v1.7.3.json`。Code → Download ZIP 是源码，不是安装程序。

升级前请导出 JSON 备份、保存输入，并从系统托盘“完全退出”旧版，再在原 Windows 账户安装。本版沿用原应用标识、数据目录与数据结构，不重建或清空已有项目、阶段、行动、计划、成果和专注记录。

安装包未进行代码签名，Windows 可能提示未知发布者；请核对来源与 SHA256，并遵守所在单位的设备管理要求。

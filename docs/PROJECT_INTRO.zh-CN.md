# ResearchFlow 1.7.2 项目介绍

最近利用闲暇时间 vibe coding 了一个面向科研人员的轻量级 Windows 桌面软件——ResearchFlow（科研续航）。我想用它整理多项目并行时的工作，把“这个项目还没做完”变成“今天先做这一小步”。

## 为什么想做这款小软件

这个想法来自我自己做科研时遇到的一些烦恼。

一个项目刚开始时干劲满满，后来反复改代码、补实验，热情慢慢被消耗，进展也就停了下来。手里同时有几个项目时，又容易在它们之间反复切换，不知道该把时间放在哪里。

还有些项目，因为各种原因暂停了一段时间。真正想重新开始时，要先回忆当时做到了哪一步、文件放在哪里、还有什么问题没有解决。光是重新梳理这些，就已经让人不太想开始了。

偶尔冒出一个好想法，也会因为眼前的工作太多而先放到一旁。过段时间再回头，思路却已经散了。

ResearchFlow 想做的，就是把这些工作和线索收在一起，让开始和重新开始都少一点阻力。

## 能用它做什么

**先看清手里的项目。** 用“问题探索”和“成果产出”整理不同工作方向，设置当前重点，按需要建立主项目和子项目。月历、时间轴和概览帮助查看近期安排。

**把项目拆成具体步骤。** 一篇论文可以先分成下载数据、撰写代码、整理结果、绘图、写作和投稿，再把主模型分析、敏感性分析、代码检查分别写成行动。既可以用列表整理，也可以在流程图里调整阶段层级。

**决定今天实际做什么。** 1.7.2 的月历不再因为项目设置了起止日期，就把中间每一天都填满。点击某一天，选择项目和研究阶段，安排当天准备推进的内容；需要连续几天再主动设置。

**记下零散待办。** 新增的“待办”适合临时事项，例如准备组会材料、确认数据版本。它独立于项目行动，未完成事项也能集中查看，不必为了记一件小事新建项目。

**工作时直接开始。** 在行动视角或桌面悬浮卡片选择当前项目，开始正计时或倒计时。结束计时只是保存这次工作，完成行动仍由自己确认。

**给中断的项目留个存档。** 重启卡记录已做工作、未解问题、关键文件线索和下次第一步。成果卡保留观察与想法，灵感池暂存新方向。需要汇报时，可以把选定项目的实际记录整理成 Markdown 周报，或复制外部 AI 总结提示词。

首次使用时，可以选择加载三个完整科研示例，看看项目、阶段和行动怎样配合，也可以直接从空白开始。示例只用于说明工作流，不代表已经取得研究结果。

## 关于隐私

科研内容常常不适合随意外发。ResearchFlow 的核心功能可以离线使用，无需账号，没有云同步或科研内容自动上传。记录保存在本机，支持 JSON 导出和恢复。

本地保存也有边界：JSON 没有应用层加密，能够访问文件的其他程序仍可能读到它。外部 AI 功能不内置模型、不需要 API Key，由用户主动复制资料和导入计划；发送到第三方平台前仍要检查内容。首次安装若缺少 WebView2，可能需要联网下载运行库。

分享软件安装包不需要附带自己的科研 JSON；也请不要把科研数据、备份或未脱敏截图上传到 GitHub。

## 欢迎试用

ResearchFlow 还是一个在持续打磨的个人项目，主要面向 Windows 10 / 11 x64。当前 1.7.2 安装包未做代码签名，下载前请核对来源及校验文件。

欢迎在 GitHub Releases 下载体验，也欢迎在 Issues 告诉我哪里不好用、遇到了什么问题，或哪些功能其实没有必要。反馈时不需要上传真实科研记录。

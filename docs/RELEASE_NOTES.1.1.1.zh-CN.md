# ResearchFlow 1.1.1

2026-10-10 · 可读性与科研规划改进

- 正文提高到14px，操作、标签和辅助说明统一到至少13px，月历短标签12px。保留原有主要标题大小，长内容可以滚动。
- 双轨改为“问题探索 / 成果产出”，编辑窗口解释用途；原“里程碑”改为“阶段性目标”。删除无操作价值的鼓励语，用功能说明和实际操作提示替代。
- 删除医学专属警示和临床专属示例，内置演示使用实验研究、材料性能与模型验证。
- 项目新增可选启动日期，与目标完成日期一起自动显示在月历和时间轴。日期条直接编辑原项目；改名、改日期或清空字段后自动更新。额外计划时段保持独立。
- 项目操作区可以直接取消重点，同时释放该项目的重点计划和手动聚焦。设为重点会选择该项目作为当前聚焦。不会删除科研记录或自动结束专注。
- 月历日期移到左上角，周末使用灰金，今日整格浅色填充，选中日使用细边框。计划条加大字号，长名称显示省略号，更多安排在日期详情查看。
- 悬浮卡片减少重复日期信息，让项目名、具体行动和开始操作保持清楚。继续使用R图标和Windows单层边框。
- 更新新手说明书、分发说明和分享包。

# ResearchFlow 1.4.1 更新说明

发布日期：2026-10-14 · Windows 10 / 11 x64

## 首次启动更容易开始

全新用户第一次打开软件时，自动显示完整浅色欢迎页。可以“体验示例科研项目”“创建我的第一个科研项目”或“暂时跳过”。取消创建仍回到欢迎；成功保存才完成引导。加载与跳过失败会保留入口及错误反馈。

已有用户、已经跳过的用户，以及恢复旧备份或删除全部项目的老用户不会被强制重新引导。完成首次选择后，概览继续以近期科研时间轴为首要科研内容。

## 本地隐私说明

欢迎页与设置共用“了解科研数据安全”入口。普通说明涵盖实际保存方式、离线核心功能、安装运行库可能联网、主动外发 AI 内容和 JSON 备份边界。可直接定位设置中现有的数据位置与备份管理区域；路径读取失败可以重试。

AI Agent 文件授权、Git 添加/提交/推送以及 .gitignore 的边界放在默认折叠的高级说明中。阅读不要求勾选协议，也不执行扫描、Git 命令或网络请求。

隐私弹窗的正文独立滚动，标题与关闭按钮固定；关闭后焦点返回原按钮，避免底部按钮遮挡长文。

## 继续复用完整示例

沿用三个正式示例、16 个阶段和 76 项行动，未重新生成第二套数据模型：

- 食物中加盐与骨质疏松症之间的相关性：下载数据 → 撰写代码 → 整理结果数据 → 绘图 → 完成最终写作 → 投稿。
- 睡眠质量与老年人跌倒风险的关联探索：明确研究问题 → 评估数据可行性 → 形成初步研究方案 → 开展可行性验证 → 确定后续研究方向。
- 骨质疏松症风险因素综述的大纲修订：梳理现有综述大纲 → 调整整体章节结构 → 完善证据组织方案 → 形成修订版大纲 → 修改与最终交付。

设置中仍可加载、补齐与安全移除。重复加载不覆盖修改；修改过或新增专注等记录的示例默认保留，可转换为普通项目。示例不会包含虚构效应量、P 值或研究结论。

## 兼容与升级

保持 schemaVersion 2、正式数据路径、原子保存与备份恢复机制，不增加数据迁移、依赖或线上服务。新用户默认浅色，已有主题选择继续保留。本版不修改 .gitignore，不自动提交或推送 Git。

升级前先导出 JSON，保存输入并通过托盘“完全退出”，再安装新版。使用手册、分享包与 SHA256 清单位于本地 `02-installers/ResearchFlow_1.4.1`。普通用户只需安装包，也可直接使用用户分享 ZIP；源码 ZIP 供开发者使用。

## 验证与限制

本版进行了单元测试、真实浏览器界面测试、类型与生产构建，以及独立 identifier 的 Windows 原生运行验证。原生验证不读取或替换正式科研记录。

真实断网/抓包、缺少 WebView2 的首次安装、Windows 125%/150% DPI、多显示器、系统睡眠与唤醒，以及其他电脑安装仍需专项验证。源码审查不等同于网络流量实测。当前安装包未作商业代码签名，Windows 可能提示未知发布者。

详细操作见 [新手使用说明书](USER_GUIDE.zh-CN.md)，数据边界见 [隐私与数据安全](PRIVACY.zh-CN.md)。

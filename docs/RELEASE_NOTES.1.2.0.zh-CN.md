# ResearchFlow 1.2.0

ResearchFlow 可为外部 AI 提供通用科研计划提示词，并把确认后的阶段和行动安全地导入现有项目。

- 新增项目内 AI 科研计划导入入口。ResearchFlow 不调用 AI、不自动读取或发送项目资料。
- 新增 `researchflow-plan` version 1 交换协议。项目类型、阶段名称和行动类型均为自由文本，适用于实验、分析、综述、竞赛等不同流程。
- 支持 JSON 粘贴或选择文件、日期和字段验证、未知字段提示、重复项提示、阶段与行动逐项选择，以及将行动追加到已有阶段。
- 新内容仅追加，不会改写已有项目字段、阶段内容或已有行动。
- 导入在单次保存中完成，并在同一数据版本上保存完整的导入前副本；设置页可恢复最近一次副本。
- 不新增运行依赖或持久化 schema 版本。

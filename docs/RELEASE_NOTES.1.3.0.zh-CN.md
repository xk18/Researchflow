# ResearchFlow 1.3.0

2026-10-12 · Windows x64

## 概览近期科研时间轴

概览优先展示过去7天和从今天起28天的科研安排。填色条为明确推进时段；空心条为未细分投入的项目日期；菱形为阶段节点，旗标为项目目标。独立时段之间保留空档，暂停项目明确标识，阶段完成状态保持人工确认。

点击项目查看详情，点击阶段定位并展开路线图；完整规划打开对应月份的三个月时间轴并强调概览范围。密集节点列表保留全部真实日期。更多项目在时间轴内滚动查看，折叠时卸载泳道并显示真实摘要。查阅不切换聚焦项目或中断专注。

折叠偏好独立保存到 desktop.json 单键，不修改科研数据格式或备份；与小组件胶囊偏好互不影响。失败时提示并保留当前界面状态。

## AI 提示词资料填写

新增独立填写区，自动带入项目名称和已设置的目标日期。项目类型、时间、研究问题、研究成果、进展、资源限制、规划范围均有示例。未知信息可明确填写“尚未确定，请 AI 协助讨论”。

填写资料位于完整提示词最前面。复制发现缺失时提醒继续填写，或主动选择复制待填模板，在发给 AI 前补充。长协作规则默认折叠，支持自定义修改；资料变化不会覆盖自定义要求，两处复制入口始终使用相同文本。

填写内容仅在本次窗口中保留，不写回项目记录，不发送到外部服务。最终交付仍是讨论确认后的 UTF-8 researchflow-plan version 1 JSON。导入的解析、预览、逐项选择、追加和导入前备份机制保持不变。

## 分发与兼容性

每次功能更新使用新版本目录 `02-installers/ResearchFlow_<版本>/`，保留历史版本。同版本已完成发布后，完整同步要求增加版本；文档维护另写报告，不冒充软件重新测试。

继续使用科研数据 schemaVersion 2，没有新增运行依赖、模型或在线服务。安装前保存并完全退出旧程序，建议先导出JSON备份。新版运行程序由维护脚本更新，桌面快捷方式仍指向06-running-program。

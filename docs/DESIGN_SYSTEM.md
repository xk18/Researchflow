# ResearchFlow 视觉系统

面向科研人员的本地研究笔记本。内容的顺序是：当前项目 → 一个具体行动 → 研究双轨 → 可接回的研究记录。概览不使用 KPI 卡片墙；项目和行动使用列表；成果使用索引和阅读区。

## 主题与组件

所有窗口共用 `src/styles.css` 的语义变量，设置中的浅色、深色和跟随系统沿用原有存储字段。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 内容背景 | `#FAF9F6` | `#1D2322` |
| 面板 | `#FFFFFF` | `#242B2A` |
| 导航背景 | `#F1F0EC` | `#191F1E` |
| 主文字 | `#242D2B` | `#E6EAE6` |
| 次文字 | `#626B67` | `#A6B1AB` |
| 行动青灰 | `#365E57` | `#A1C8B8` |
| 交付灰金 | `#85734F` | `#C8B58C` |

4px 基础间距，常用 8 / 12 / 16 / 24 / 32px。控件圆角 6px，主行动区 8px，弹窗与悬浮窗口 12px，胶囊 22px。正文区没有投影，浮动窗口和弹窗才使用阴影。按钮 32px，图标按钮 28px，悬浮窗口主要按钮 36px；输入框最小高度 34px。

字体使用 Windows 原生 Segoe UI Variable / Segoe UI，中文回退 Microsoft YaHei UI / Microsoft YaHei，其他系统回退 Noto Sans CJK SC / sans-serif。正文 14px，操作与元信息 13px，月历短标签 12px，标题 26px，主要行动 24px，悬浮行动 20px。标题字重 600，正文行高 1.6，科研文本 1.8–1.9。计时使用等宽数字，不加载远程字体。

按钮提供 hover、active、disabled 和 2px 可见键盘焦点。弹窗沿用原生 dialog 焦点限制、Escape 与未保存确认，长表单的保存栏固定在底部。错误保留输入并提供重新读取。空状态提供对应的下一步。

## 三种窗口

- 胶囊 120×44：展开入口、科研标记和独立拖动柄。
- 悬浮卡片 320×400：主要项目、推荐行动、固定开始/完成按钮；问题探索 / 成果产出 状态；动力选择、重启、灵感和管理入口。长中文标题限制显示行数，完整标题提供 tooltip，正文可滚动，主要操作不随长内容移出窗口。
- 管理面板 900×650，最小 720×560：176px 分组导航、轻量标题栏、阅读内容区。包含科研项目、双轨、重启卡、成果、灵感、状态与设置。窄视口会调整导航和索引布局。

尺寸是 Tauri logical pixels，由 Windows 决定物理缩放。浏览器 DPR/视口模拟不能替代多显示器和真实 Windows DPI 验收。

Windows 悬浮窗口只使用系统阴影附带的圆角边框，内容填满窗口，不再叠加 CSS 胶囊或卡片轮廓。浏览器预览与其他平台保留 CSS 边界。品牌标记统一使用 ResearchFlow 的首字母 R；界面为青灰线条，应用、托盘与快捷方式图标为青灰底白色 R。图标矢量源为 `src-tauri/icons/icon.svg`。

## 保留的行为

原子存储、串行写入、科研双轨转换和原生窗口桥接继续复用。V1.1 显式迁移到schema2，推荐增加人工聚焦/当日重点优先，计时扩展为独立会话状态机；原有成果、灵感和状态能力保留。

成果卡索引只改变选中记录的显示；搜索和项目筛选仍使用原记录。阅读区显示所有已填写的字段，编辑器按观察/假设/证据/解释/局限等属性排列，并保留可选补全方式。

## V1.1 规划与行动

科研规划沿用纸张底色与青灰/灰金语义。月历按自然月、周一起始，统一周高度，连续计划跨列并在周界断开，项目启动、目标日期和阶段目标使用轻量标记，额外记录放入日期详情。时间轴保持同一数据源，同项目重叠时段分行，日期标尺、今日细线与项目目标点分开；无日期阶段不编造时间条。

月历的今天使用整格淡青灰填充，日期数字固定在左上角并以青灰加粗，不叠加圆形底色；所选日期另以细边框标识。浅深主题共用tint与accent变量，今天和日期选择各有独立语义。

路线图使用可折叠的纵向阶段列表，状态、排序和操作在展开后显示，行动使用轻量行。行动视角突出项目、当前阶段和一项下一步行动；长标题可换行，计时操作保持可见。导航按工作视角、研究工作、研究记录分组。新增页面不引入统计卡片墙、甘特库或远程字体。

截图复审修正：连续周时间条替代每日重复标签；重叠时段分行；用短标签显示目标日期；对齐时间轴标尺与日期区域；压缩行动页重复留白，使900×650首屏可见开始操作。Windows单层系统边框、阴影与R品牌标记保持。

## 1.1.1 可读性迭代

正文14px，按钮、标签和辅助说明最小13px，月历事件12px。保留26px页标题、24px主要行动和20px悬浮行动。计划格左上角放置日期，整格淡色填充今天，周末使用灰金，长项目名称截断并提供完整标题。溢出的安排在日期详情完整显示。

项目日期是单一来源，月历与时间轴实时投影，不创建重复计划。项目新增可选startDate，不改变schemaVersion 2；旧记录无需补填。取消重点会释放同项目计划的重点和手动选择，保留计时和科研内容。
# 1.3.0 概览与提示词扩展

概览沿用现有暖白、墨青、灰金与系统中文字体。近期时间轴只用一层8px边框，周刻度与泳道共用名称列及稳定滚动条占位；今日按本地自然日中点绘制，项目条不表达完成百分比。推进条填色、总体项目日期空心、暂停虚线，节点有可见焦点与完整名称；密集节点使用可键盘关闭的列表。

项目名称列152px，窄窗136px，最多两行；完整标题保留在按钮说明与项目页。首屏空间优先给予35天时间关系和“开始”操作，当前主要项目用轻量横行，长内容保留滚动，不裁掉操作。

AI资料区用两列有标签字段，窄窗改一列。长提示词规则置于details，完整文本只读预览，自定义规则单独可编辑，避免自动生成覆盖手动内容。缺失资料反馈滚动到可见位置并提供继续填写或复制待填模板。

## 1.4 首次体验

延续雾白 #faf9f6、纸白 #ffffff、深墨 #242d2b、青灰 #365e57、细线 #e3e5df。欢迎入口是概览中的单一阅读区域，20px标题、13px说明、4/8px间距，沿用 Windows 中文系统字体，不新增营销弹窗或动效。演示标记使用已有中性小标签；移除预览逐项目显示关联数量，修改提示用灰金，不使用警告大色块。浅色默认只适用于无偏好设置，不覆盖深色和跟随系统。


## 1.7 简约界面与可调字号

移除重复页面说明、口号和无内容空状态文案；保留业务字段、必要空状态、错误、隐私与删除确认。项目背景按需展开；项目色复用月历的稳定ID映射，18%低饱和底色与细边框区分，深色使用语义变量。项目名称、状态和示例标记继续提供文本识别。

行动视角只保留一处项目选择和一条阶段上下文，中心行动、图形时钟、圆形图标操作；详情收纳到更多菜单。图标保留title、aria-label和键盘焦点。

文字使用rem，默认基准14px，可保存为12–18。窗口尺寸、日期网格与控制栏几何仍使用px，避免调字号导致窗口超出桌面。小组件正文局部滚动，主操作保留在底部。自定义寄语字号也随全局基准缩放。

流程图为真实记录的可编辑投影：阶段所属阶段可选，行动仍关联一个阶段。连线表示归属。展开、缩放与节点选择是临时视图状态，层级、顺序、状态和内容立即持久化。选择延迟240ms以区分双击，防止侧栏出现导致第二击偏移。


## 1.7.1 局部视觉回退

行动视角恢复1.6.0的项目/阶段信息区与独立行动卡片，操作使用短文字按钮，专注采用数字计时。科研项目恢复连续列表、细分隔线与轻量子项目缩进，取消项目身份色块和彩色边框。保留背景按需查看与精简文案。悬浮窗、可编辑流程图、全局rem字号及其持久化保持。月历的项目标签颜色继续使用原有规则。


## 1.7.2 待办与按需月历

待办沿用中性连续列表、细线分隔与图标操作，不增加统计卡片。日期导航保持一行，窄窗口允许工具栏外层换行。完成勾选采用主题强调色；文字可换行，完成内容以细划线和次级文字显示。
月历只投影显式计划和日期节点。项目总体范围仅用于时间轴展示和安排时的项目推荐。研究阶段是计划的可选关联，颜色仍由项目ID稳定分配。新增计划重点默认关闭，编辑已有记录保留原值。

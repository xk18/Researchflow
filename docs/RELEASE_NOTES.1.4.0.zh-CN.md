# ResearchFlow 1.4.0

新用户以浅色科研工作台开始，可自主加载完整示例或从空白创建自己的研究。升级不会向已有工作区自动加入演示数据。

- 默认主题改为浅色，原有深色和跟随系统偏好继续保留。HTML、CSS 和管理窗口初始底色统一为雾白。
- 概览空状态提供「加载示例项目 / 从空白开始」。选择、保存与恢复旧备份后均不会重复打扰。
- 三个完整示例共 16 个阶段、76 项行动：完整观察性研究论文、早期问题探索、综述大纲修订。全部使用现有正式模型和存储，不生成统计结论或假专注历史。
- 示例加载日确定近期日期，之后不漂移；月历、时间轴、概览、路线图、行动和悬浮组件读取同一份数据。
- 设置中的「示例科研项目」支持补齐缺失示例和安全移除。稳定来源标识用于去重，同名真实研究不受影响。
- 编辑过或含新增记录的示例默认不勾选；可保留为普通项目，全部关联内容继续保留。明确选择删除修改项目时需额外确认。
- 移除前保留本地安全副本；确认期间内容变化或存在未结束专注时阻止操作。失败不误报成功。

数据格式仍为 schemaVersion 2，仅增加可选的 `settings.onboarding`、`project.sampleKey` 和 `project.sampleBaseline`，不迁移、不重置已有项目。
